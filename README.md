## Overview
A machine learning web application that classifies airline customer feedback
(from Twitter) as **positive**, **neutral**, or **negative** using a Support
Vector Machine trained on the Twitter US Airline Sentiment Dataset.

## Model Performance
| Metric | Score |
|---|---|
| Accuracy | 79.66% |
| Macro F1 | 0.7342 |
| Classifier | LinearSVC |
| Features | TF-IDF Unigram |
